## Метод дихотомии

# Требования к приложению
* Разработать приложение на языке C# в оболочке WinForms. Обеспечить отказоустойчивость для входных данных, оповещая пользователя о некорректных / недопустимых введённых значениях.
* Ввод входных данных организовать с использованием стандартных компонентов WinForms. Параметры a, b, e – вещественные числа, f(x) – строка с формулой.
* Вывести график функции и найденную точку минимума с использованием стандартных компонентов WinForms или сторонних библиотек.
* Элементы взаимодействия, не предоставляющие пользовательского ввода (кнопка «Рассчитать», «Очистить» и аналогичные) размещать в MenuStrip.

# Задание
Используя метод половинного деления (дихотомии) найти локальный минимум заданной точности e функции f(x) на интервале [a, b].

# Сборка и запуск программы на Arch Linux
В системе должны быть установлены пакеты mono и mono-msbuild:
sudo pacman -S mono mono-msbuild

Для сборки использовать:
msbuild Sorter.csproj

Для запуска:
mono bin/Debug/Sorter.exe
